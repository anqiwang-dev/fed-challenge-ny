# FNCE 613 Fed Challenge · Team NY Fed

Interactive briefing for our December 2026 FOMC recommendation: raise the federal funds target range by 25 basis points, to 4.00%–4.25%.

**Live page:** https://anqiwang-dev.github.io/fed-challenge-ny/

- One self-contained `index.html` (plain JavaScript and SVG, no build step).
- Charts use official data from FRED (Federal Reserve Bank of St. Louis), retrieved November 24, 2026. Every source is listed on the page's Sources chapter.
- Keys: ← → move between chapters, 0–9 jump to one, F toggles full screen.

Classroom exercise for FNCE 613. The 25 bp hike is a proposed classroom position, not official Federal Reserve policy, and this project is not affiliated with the Federal Reserve.
